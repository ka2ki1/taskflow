# 要件定義

## 1. 概要
TaskFlow はチームでプロジェクトとタスクを管理する Web アプリ。
カンバン形式でタスクの状態を共有し、担当者・期限・コメントでやり取りできる。

## 2. 想定ユーザー
- 3〜10人程度の開発チーム・小規模チーム
- 1人が複数のプロジェクトに所属する

## 3. 機能要件

| ID | 機能 | 詳細 |
|---|---|---|
| F-01 | ユーザー登録 | 名前・メール・パスワード（8文字以上・確認入力） |
| F-02 | ログイン/ログアウト | セッション Cookie。ログイン試行は 1分5回まで |
| F-03 | プロジェクト一覧 | 自分が所属するものだけ表示。ページネーション |
| F-04 | プロジェクト作成/編集/削除 | 作成者が owner。編集は owner/admin、削除は owner のみ（論理削除） |
| F-05 | メンバー管理 | メールで追加、役割 admin/member、削除。owner は削除不可 |
| F-06 | タスク CRUD | タイトル、説明、ステータス、優先度、担当者、期限 |
| F-07 | カンバン表示 | todo / in_progress / done の3列 |
| F-08 | タスク絞り込み | 担当者、キーワード |
| F-09 | コメント | タスクにコメント投稿、本人のみ削除 |

## 4. 権限マトリクス

| 操作 | owner | admin | member | 非メンバー |
|---|---|---|---|---|
| プロジェクト閲覧 | ○ | ○ | ○ | × (403) |
| プロジェクト編集 | ○ | ○ | × | × |
| プロジェクト削除 | ○ | × | × | × |
| メンバー追加・削除 | ○ | ○ | × | × |
| タスク作成・編集 | ○ | ○ | ○ | × |
| タスク削除 | ○ | ○ | 自分が作成したもののみ | × |
| コメント削除 | 本人のみ | 本人のみ | 本人のみ | × |

## 5. 非機能要件

### セキュリティ
- CSRF 対策（Sanctum の XSRF-TOKEN）
- パスワードは bcrypt でハッシュ化
- 全 API で Policy による認可チェック
- ログインのレート制限

### 性能
- N+1 クエリを出さない（eager loading）
- 一覧はページネーション
- 検索条件にインデックスを張る

### 保守性
- Controller は薄く。入力検証は FormRequest、出力は API Resource、業務処理は Action クラス
- PR は CI 通過必須

### 運用
- `/up` でヘルスチェック
- ログはコンテナ向けに stderr へ出力
- 環境ごとの違いは `.env` だけで切り替える

## 6. スコープ外（v1.0 ではやらない）
- 通知（メール・プッシュ）
- ファイル添付
- ドラッグ&ドロップでの並び替え
- モバイルアプリ
